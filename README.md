# Sky Notes — Weather App

A responsive weather website built with HTML, CSS, and JavaScript. Search for a city to view current weather conditions.

## Features
- Search for a city by name
- Shows current temperature and apparent temperature
- Shows weather conditions, humidity, and wind speed
- Responsive layout for laptop and mobile screens
- Helpful error messages for missing cities or network problems

## How to run
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Enter a city name and click **Search**.
4. An internet connection is required to retrieve live weather data.

## Data source
Weather and geocoding data are provided by [Open-Meteo](https://open-meteo.com/). This project uses its public APIs and does not require an API key. Weather values can be delayed or unavailable if the service or internet connection is down.

## Built with
- HTML
- CSS
- JavaScript (Fetch API)
- Open-Meteo Geocoding API and Forecast API
